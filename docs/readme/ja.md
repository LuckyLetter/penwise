# Penwise

[English とほかの言語](../../README.md) · **日本語**

Mac のどの入力欄でも、より良い英語を：**⌃⌥P** を押して、変更を確認し、**Return** を押すだけ。

<img src="../demo.gif" width="640" alt="入力欄で Penwise を使う：⌃⌥P で修正を表示し、Tab で推敲に切り替え、Return で文章を反映。">

- **どこでも英語を直せる**：メール、チャット、文書、ブラウザで。コピー＆ペーストは不要です。
- **直しながら学べる**：変更ごとに、ルールの短い説明が付きます。
- **言えない表現は日本語で**：日本語や `[[?]]` で書いておくと、Penwise が英語にします。
- **安全**：数字、引用、コード、リンクを勝手に変えません。変更はひとつずつ元に戻せます。

## インストール

1. **[Penwise.dmg](https://github.com/LuckyLetter/penwise/releases/latest/download/Penwise.dmg)** をダウンロードして開き、
   Penwise をアプリケーションフォルダにドラッグします。そこから開いてください。
   - macOS がアプリを確認できないと表示したら：**完了** をクリックし、**システム設定 → プライバシーとセキュリティ** を開いて
     **このまま開く** をクリックします。
2. 開いたウインドウに、AI サービスの **API エンドポイント**、**API キー**、**モデル** を入力し、**保存** を押します。
   - **どれを使えばいいかわからない場合は、[OpenRouter](https://openrouter.ai) の `openai/gpt-oss-20b` がおすすめです**：
     速く、ほぼ無料です（1 ドルで 1 万回以上チェックできます）。[openrouter.ai](https://openrouter.ai/settings/keys) でキーを作成して少額のクレジットを
     追加し、キーをコピーしてから API キーの欄をクリックすると、キーと API エンドポイントが自動で入ります。モデルには
     `openai/gpt-oss-20b` と入力します。
   - 文章を Mac の外に出したくない場合は、Mac 上の無料モデルを使えます：[Ollama](../GUIDE.md#a-model-on-your-mac-ollama)（英語）。
3. macOS に聞かれたら、**アクセシビリティ** で **Hammerspoon** をオンにします。これで Penwise が文章を読み取り、置き換えられます。

## 使い方

入力欄をクリックして **⌃⌥P** を押します。**Return** で修正を反映、**Esc** で閉じます。

| キー | できること |
| ---- | ---------- |
| **⌃⌥P** | 誤りを直す |
| **⌃⌥⇧P** | わかりやすく、自然な文に推敲する |
| **⌃⌥⌘P** | パネルを開かずにすぐ直す |

そのほかの機能は、メニューバーのペン先アイコン（Penwise のメニュー）にあります：*設定*、*よくある修正*、*設定をチェック*、
*アップデート*、*アンインストール*。

## 言語

Penwise は English、中文、日本語、한국어 に対応しています：**設定** の上部で選べます。文章はいつも英語としてチェックされます。
