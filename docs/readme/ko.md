# Penwise

[English 및 다른 언어](../../README.md) · **한국어**

Mac의 어느 입력란에서나 더 나은 영어로: **⌃⌥P**를 누르고, 수정 내용을 확인한 뒤, **Return**을 누르세요.

<img src="../demo.gif" width="640" alt="입력란에서 Penwise 사용: ⌃⌥P로 수정 표시, Tab으로 다듬기 전환, Return으로 글 반영.">

- **어디서나 영어 교정**: 메일, 채팅, 문서, 브라우저에서. 복사하고 붙여 넣을 필요가 없습니다.
- **고치면서 배우기**: 수정마다 규칙을 짧게 설명해 줍니다.
- **모르는 표현은 한국어로**: 한국어나 `[[?]]`로 써 두면 Penwise가 영어로 채워 줍니다.
- **안전**: 숫자, 인용, 코드, 링크는 마음대로 바꾸지 않으며, 수정은 하나씩 되돌릴 수 있습니다.

## 설치

1. **[Penwise.dmg](https://github.com/LuckyLetter/penwise/releases/latest/download/Penwise.dmg)**를 내려받아 열고,
   Penwise를 응용 프로그램 폴더로 드래그하세요. 그다음 거기서 여세요.
   - macOS가 앱을 확인할 수 없다고 하면: **완료**를 클릭하고, **시스템 설정 → 개인정보 보호 및 보안**을 열어 **그래도 열기**를
     클릭하세요.
2. 열린 창에 AI 서비스의 **API 엔드포인트**, **API 키**, **모델**을 입력하고 **저장**을 누르세요.
   - **무엇을 쓸지 모르겠다면 [OpenRouter](https://openrouter.ai)의 `openai/gpt-oss-20b`를 추천합니다**: 빠르고 거의
     무료입니다(1달러로 1만 번 넘게 검사할 수 있습니다). [openrouter.ai](https://openrouter.ai/settings/keys)에서 키를 만들고 크레딧을 조금 충전한 뒤,
     키를 복사하고 API 키 칸을 클릭하면 키와 API 엔드포인트가 자동으로 채워집니다. 모델에는 `openai/gpt-oss-20b`를
     입력하세요.
   - 글을 Mac 밖으로 보내고 싶지 않다면 Mac에서 무료 모델을 쓸 수 있습니다: [Ollama](../GUIDE.md#a-model-on-your-mac-ollama)(영어).
3. macOS가 물어보면 **손쉬운 사용**에서 **Hammerspoon**을 켜세요. 그래야 Penwise가 글을 읽고 바꿀 수 있습니다.

## 사용법

아무 입력란이나 클릭하고 **⌃⌥P**를 누르세요. **Return**을 누르면 수정한 글이 들어가고, **Esc**를 누르면 닫힙니다.

| 키 | 하는 일 |
| -- | ------- |
| **⌃⌥P** | 오류 교정 |
| **⌃⌥⇧P** | 더 명확하고 자연스럽게 다듬기 |
| **⌃⌥⌘P** | 패널 없이 바로 교정 |

나머지 기능은 메뉴 막대의 펜촉 아이콘(Penwise 메뉴)에 있습니다: *설정*, *자주 하는 수정*, *설정 확인*, *업데이트*,
*제거*.

## 언어

Penwise는 English, 中文, 日本語, 한국어를 지원합니다: **설정** 위쪽에서 고르세요. 글은 언제나 영어로 검사합니다.
